# Robot API Test

Este projeto é uma POC de testes automatizados de API utilizando Robot Framework e RequestsLibrary. O objetivo é demonstrar como criar testes de cadastro de usuário, validação de campos e geração de massa de dados dinâmica.

---

## Pré-requisitos

- Python instalado
- Git instalado
- Navegador para visualizar logs (opcional)

---

```bash
git clone https://github.com/amandavruiz/robot-api-test.git
